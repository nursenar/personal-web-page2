# 🌸 Hatice Nursena Resüloğlu | Personal Portfolio

### 💜 GMT458 – Web GIS | Assignment 1: Personal Web Page

Welcome to my little corner of the internet! 🌷

This is my personal portfolio website, developed as part of the **GMT458 – Web GIS** course at Hacettepe University.

The website was built using **HTML5, CSS3, JavaScript, and OpenLayers** to introduce myself, share my experiences and interests, and explore interactive web mapping technologies.

My goal was to create a website that is not only functional but also colorful, personal, interactive, and enjoyable to explore.

## ✨ Website Features

### 🌸 1. Flower Animation

The homepage includes a decorative falling-flower effect inspired by my love of flowers and pastel aesthetics.

The animation was designed using HTML, CSS animations, and JavaScript experiments.

### 🌙 2. Dark / Light Mode

Visitors can switch between light and dark themes.

The selected theme is saved using the browser's `localStorage`, allowing the preference to remain active when navigating between pages.

### 🎨 3. Responsive Design

The website uses responsive layouts to adapt to different screen sizes, including desktop computers, tablets, and smartphones.

### 📸 4. Photo Galleries

Personal photographs are displayed on the About Me page.

The Maps page also includes city-related photograph galleries.

### 🧶 5. Interactive Hobby Cards

The Hobbies page features animated cards representing crochet, badminton, and hiking.

Hover effects make the page more interactive.

### 💌 6. Social Media Links

The Contact page provides clickable links to my email and social media accounts.

The cards feature hover animations, including scaling, rotation, and color transitions.

### 🖨️ 7. Print-Friendly CV

The CV page includes a **Save as PDF** button.

This feature opens the browser's print dialog, allowing visitors to save the CV as a PDF document.

## 🗺️ Interactive Map – Where is the Nurs?

One of the main features of this project is an interactive map created using **OpenLayers**.

The map displays cities across Türkiye that I have visited.

### 📍 Cities Included

1. Kastamonu
2. Ankara
3. İstanbul
4. Eskişehir
5. Gaziantep
6. Sinop
7. Bursa
8. İzmir
9. Balıkesir
10. Samsun

### 🔎 Map Features

- Interactive zooming and panning
- City markers
- City selection by clicking markers
- Photo galleries for cities with available photographs
- Automatic zoom animation after city selection
- Marker visibility based on zoom level
- Configuration to prevent horizontal map wrapping
- Alternative basemap integration using Esri services

The project helped me understand how JavaScript and OpenLayers can be combined to visualize geographic information interactively.
