### 💜 GMT458 – Web GIS | Assignment 1: Personal Web Page

Welcome to my little corner of the internet! 🌷

## ✨ Website Features

### 🌙 1. Dark / Light Mode

Visitors can switch between light and dark themes.

The selected theme is saved using the browser's `localStorage`, allowing the preference to remain active when navigating between pages.

### 🎨 2. Responsive Design

The website uses responsive layouts to adapt to different screen sizes, including desktop computers, tablets, and smartphones.

### 📸 3. Photo Galleries

Personal photographs are displayed on the About Me page.

The OpenLayers map also includes city-related photograph galleries.

### 🧶 4. Interactive Hobby Cards

The Hobbies page features animated cards representing crochet, badminton, and hiking.

Hover effects make the page more interactive.

### 📊 5. Visual Projects Table

The Projects page includes an HTML table featuring images, titles, categories, and descriptions.

The table presents four subjects:

- 🧶 Crochet Creations
- 🥾 Hiking Adventures
- 🏸 Badminton
- 🌐 Personal Portfolio

The table uses alternating row colors, hover effects, rounded images, and a responsive horizontal scrolling layout on smaller screens.

### 💌 6. Social Media Links

The Contact page provides clickable links to my email and social media accounts.

The cards feature hover animations, including scaling, rotation, and color transitions.

### 🖨️ 7. Print-Friendly CV

The CV page includes a **Save as PDF** button.

This feature opens the browser's print dialog, allowing visitors to save the CV as a PDF document.

## 🗺️ Interactive Maps – Where is the Nurs?

One of the main features of this website is the integration of two different web mapping libraries: **OpenLayers** and **Leaflet**.

Both maps display cities across Türkiye that I have visited.

### 📍 Cities Included

1. Kastamonu
2. Ankara
3. İstanbul
4. Eskişehir
5. Gaziantep
6. Sinop
7. Bursa
8. İzmir
9. Balıkesir
10. Samsun

### 🌍 OpenLayers Map

The first interactive map was developed using OpenLayers.

**Features include:**

- Interactive zooming and panning
- Markers representing visited cities
- City selection by clicking markers
- Photo galleries for cities with available photographs
- Zoom-based marker visibility
- Configuration to prevent horizontal map wrapping
- Basemap integration

### 📍 Leaflet Map

The second interactive map was developed using Leaflet.

It complements the OpenLayers map by providing an alternative interactive map experience.

**Features include:**

- Interactive zooming and panning
- Ten visited-city locations
- Purple circular markers
- Popup windows displaying city names
- Zoom-dependent marker visibility
- Markers appearing at zoom level 7 and above
- Map bounds and tile-layer settings to prevent repeated world maps
- Esri World Street Map basemap

### 🔎 Web GIS Concepts Applied

Through these maps, I learned how to:

- Display geographical locations using latitude and longitude
- Work with map projections and coordinates
- Create interactive markers and popup windows
- Control marker visibility using zoom events
- Configure map layers and basemaps
- Prevent horizontal world repetition
- Integrate multiple mapping libraries into one website

Developing both maps helped me compare different approaches to interactive geographic visualization.
